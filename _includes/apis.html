Equipe's APIs

  • Federation API You're here For federations that connect their own system to Equipe. You build the web services and Equipe calls them.
  • app.equipe.com API For working directly with app.equipe.com: people, horses, payments and more. github.com/equipe/equipe-api
  • online.equipe.com API Show schedules, start lists and results from online.equipe.com. online.equipe.com/api/docs
